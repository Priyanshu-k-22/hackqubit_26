# UPI SHIELD (frontend prototype)
`npm install && npm run dev`. Runs fully in demo mode with synthetic data. Set `VITE_API_BASE_URL` (see `.env.example`) to call a real backend; all calls live in `src/services/api.js` (scannerApi, threatApi, campaignApi, reportApi, feedbackApi). Replace `mockAnalyze` without touching UI code.
Camera access needs HTTPS or localhost. PDF export = browser print dialog (no file is generated by the app).
